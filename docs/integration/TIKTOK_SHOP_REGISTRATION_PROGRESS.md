## 6. Thong Tin Ky Thuat Can Thiet

### 6.1 TikTok Shop API Endpoints

| API | Endpoint | Method |
|-----|----------|--------|
| Get Orders | `/api/affiliate/orders/search` | POST |
| Get Products | `/api/products/search` | POST |
| Generate Link | `/api/affiliate/links/generate` | POST |

### 6.2 Affiliate Link Format

```
# Format du kien:
https://affiliate.tiktok.com/r
  ?product_id={PRODUCT_ID}
  &affiliate_id={APP_KEY}
  &sub_id={TRACKING_CODE}

# Tracking code format (giong Shopee):
CB{userId}_{clickId}_{timestamp}
Vi du: CB1_100_20251226150000
```

### 6.3 Authentication

```
# OAuth 2.0 Token Request
POST https://auth.tiktok-shops.com/api/v2/token/get

Headers:
  Content-Type: application/json

Body:
{
  "app_key": "{APP_KEY}",
  "app_secret": "{APP_SECRET}",
  "grant_type": "authorized_code"
}

# API Request
GET/POST https://open-api.tiktokglobalshop.com/api/...

Headers:
  Authorization: Bearer {ACCESS_TOKEN}
  x-tts-access-token: {ACCESS_TOKEN}
```
