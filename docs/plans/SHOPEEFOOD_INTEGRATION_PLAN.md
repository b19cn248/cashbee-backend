### 3.2 ShopeeFood Affiliate Link Builder

```
Package: com.cashbee.application.util.affiliate
Class: ShopeeFoodAffiliateLinkBuilder
```

**Key Differences from Shopee E-commerce:**

| Feature | Shopee E-commerce | ShopeeFood |
|---------|-------------------|------------|
| Base URL | `s.shopee.vn/an_redir` | `shopeefood.vn/now-food/affiliate/landing-page` |
| Affiliate ID Param | `affiliate_id` | `mmp_pid` |
| Tracking Param | `sub_id` | Custom approach needed |
| URL Encoding | `origin_link={encoded_url}` | Direct parameters |

**Proposed Implementation:**

```java
@Component
public class ShopeeFoodAffiliateLinkBuilder {

    private static final String SHOPEEFOOD_AFFILIATE_BASE = "https://shopeefood.vn/now-food/affiliate/landing-page";

    /**
     * Build ShopeeFood affiliate link.
     *
     * Note: ShopeeFood does NOT support custom sub_id like Shopee E-commerce.
     * Tracking must be done via the mmp_pid (affiliate ID) and uls_trackid (auto-generated).
     *
     * For CashBee tracking, we will:
     * 1. Store the generated uls_trackid when user clicks our link
     * 2. Match orders via mmp_pid in CSV reports
     * 3. Use order time + user activity log for additional matching
     */
    public String build(String restaurantId, String brandId, String affiliateId) {
        return String.format(
            "%s?restaurantId=%s&brandId=%s&mmp_pid=%s&shareChannel=cashbee",
            SHOPEEFOOD_AFFILIATE_BASE,
            restaurantId,
            brandId != null ? brandId : "0",
            affiliateId
        );
    }
}
```

## 6. Critical Considerations

### 6.1 Tracking Challenge

**Problem:** ShopeeFood có thể KHÔNG hỗ trợ custom `sub_id` như Shopee E-commerce.

**Current Shopee E-commerce Flow:**
1. User clicks link with `sub_id=TRACKING_CODE`
2. Shopee stores `sub_id` in cookie
3. CSV export includes `Sub_id1` column
4. Match order to click via `Sub_id1`

**Potential ShopeeFood Flow:**
1. User clicks link with `mmp_pid=AFFILIATE_ID` (no custom tracking)
2. Shopee generates `uls_trackid` automatically
3. CSV may only include `mmp_pid` (our affiliate ID)
4. **Cannot distinguish orders from different users!**

**Solution Approaches:**

| Approach | Description | Pros | Cons |
|----------|-------------|------|------|
| A. Time-based matching | Match orders within 5 mins of click | Simple | Inaccurate with many users |
| B. Proportional distribution | Divide commission equally among recent clickers | Fair | Not accurate |
| C. First-click attribution | Oldest pending click gets the order | Simple | May not be accurate |
| D. API Integration | Use Shopee API if available | Accurate | May require partnership |

**Recommended:** Start with Approach A (time-based) + user activity logging, then improve based on actual data.

### 6.2 Commission Cap Handling

ShopeeFood có giới hạn hoa hồng tối đa 10,000 VND/đơn. Công thức điều chỉnh:

```java
// When total expected commission > max cap
actualCommission = (expectedCommission / totalExpectedCommission) * maxCap;
```

### 6.3 Customer Type Impact

| Customer Type | Vietnamese | Expected Commission Rate |
|---------------|------------|-------------------------|
| New Customer | Khách mới | Higher (e.g., 5-10%) |
| Existing Customer | Khách hiện tại | Lower (e.g., 1-3%) |

This affects cashback calculation - need to reflect in user's expected earnings.
