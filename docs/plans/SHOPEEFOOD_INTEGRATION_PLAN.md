| Attribute | Value |
|-----------|-------|
| Cookie Period | 7 ngay |
| Max Commission | 10,000 VND/don |
| Customer Types | Khach moi (cao hon) / Khach cu (thap hon) |
| Link Domain | `shopeefood.vn` hoac `shopee.vn/now-food` |
| Affiliate ID Format | `mmp_pid=an_XXXXXXXXXXX` |

## 3. Technical Design

### 3.1 ShopeeFood URL Parser

**Supported URL Formats:**
1. `https://shopeefood.vn/now-food/affiliate/landing-page?restaurantId=123&brandId=0`
2. `https://shopee.vn/now-food/affiliate/landing-page?restaurantId=123`
3. `https://shopeefood.vn/ho-chi-minh/banh-mi-huynh-hoa`

### 3.2 ShopeeFood Affiliate Link Builder

**Key Differences from Shopee E-commerce:**

| Feature | Shopee E-commerce | ShopeeFood |
|---------|-------------------|------------|
| Base URL | `s.shopee.vn/an_redir` | `shopeefood.vn/now-food/affiliate/landing-page` |
| Affiliate ID Param | `affiliate_id` | `mmp_pid` |
| Tracking Param | `sub_id` | Custom approach needed |

### 3.3 ShopeeFood CSV Parser

**Expected CSV Columns:**
- Order ID, Order Status, Order Time
- Restaurant ID, Restaurant Name, Brand ID
- Customer Type (Khach moi / Khach hien tai)
- Order Value, Commission Rate, Actual Commission
