## 2. Mô Hình Hoạt Động

### 2.1. Vai Trò Trung Gian

```
┌─────────────┐         ┌─────────────┐         ┌─────────────┐
│  Merchant   │ ◄─────► │    ADPIA    │ ◄─────► │  Publisher  │
│ (Nhà bán)   │         │  (Trung gian)│         │ (Đối tác)   │
└─────────────┘         └─────────────┘         └─────────────┘
       │                       │                       │
       ▼                       ▼                       ▼
  Cung cấp              - Tracking              Quảng bá sản
  sản phẩm              - Báo cáo               phẩm/dịch vụ
  + hoa hồng            - Thanh toán
                        - Hỗ trợ kỹ thuật
```

### 2.2. Các Mô Hình Thanh Toán

| Model | Mô tả | Ví dụ |
|-------|-------|-------|
| **CPS** (Cost Per Sale) | Hoa hồng theo % giá trị đơn hàng | Shopee, Lazada, Tiki |
| **CPO** (Cost Per Order) | Hoa hồng cố định mỗi đơn hàng | Đặt đồ ăn, taxi |
| **CPA** (Cost Per Action) | Hoa hồng theo hành động cụ thể | Đăng ký tài khoản, mở thẻ |
| **CPL** (Cost Per Lead) | Hoa hồng theo lead/khách hàng tiềm năng | Bảo hiểm, tài chính |

## 7. API Dành Cho Developer

### 7.1. Tổng Quan

ADPIA cung cấp REST API cho Publisher để tích hợp hệ thống.

**Repository tham khảo:** [Publisher_api trên GitHub](https://github.com/technicaladpia/Publisher_api)

### 7.2. Các Endpoint Chính

| Endpoint | Mô tả | Auth |
|----------|-------|------|
| `GET /v2/merchant/get_merchants_valid` | Danh sách merchant đang hoạt động | Không |
| `GET /v2/merchant/get_merchant_program_description` | Mô tả chương trình affiliate | Không |
| `GET /v2/affiliate/get_conversions` | Dữ liệu chuyển đổi/đơn hàng | Basic Auth |
| `GET /v2/affiliate/get_promo_code` | Mã khuyến mãi theo merchant | Basic Auth |

### 7.3. Authentication

```
Authorization: Basic base64(api_key:api_secret)
```

### 7.4. Response Format

```json
{
  "message": "Success",
  "description": "Data retrieved successfully",
  "code": 200,
  "data": [...]
}
```

### 7.5. Ví Dụ Code PHP

```php
<?php
// Lấy danh sách merchant
$url = "https://api.adpia.vn/v2/merchant/get_merchants_valid";
$params = [
    'mid' => 'merchant_id',  // Optional
    'adtype' => 'CPS'        // Optional: CPS, CPO, CPA
];

$ch = curl_init($url . '?' . http_build_query($params));
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
curl_close($ch);

$data = json_decode($response, true);
print_r($data);
?>
```
