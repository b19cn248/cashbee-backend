## 📋 API Details

### Endpoint

```
POST https://affiliate.shopee.vn/api/v3/gql?q=productOfferLinks
```

### GraphQL Query Structure

```graphql
query batchGetProductOfferLink(
  $sourceCaller: SourceCaller!
  $productOfferLinkParams: [ProductOfferLinkParam!]!
  $advancedLinkParams: AdvancedLinkParams
) {
  productOfferLinks(
    productOfferLinkParams: $productOfferLinkParams
    sourceCaller: $sourceCaller
    advancedLinkParams: $advancedLinkParams
  ) {
    itemId
    shopId
    productOfferLink
  }
}
```

## 🚫 Why This Doesn't Work

### 1. Session Management Nightmare

```java
// You need to:
1. Login to Shopee Affiliate
2. Extract cookies from browser
3. Store cookies in backend
4. Refresh cookies before they expire
5. Handle CSRF token rotation
6. Handle 2FA if enabled
```

### 2. Anti-Bot Detection

```
❌ Request blocked: Invalid x-sap-sec
❌ Request blocked: Missing browser fingerprint
❌ Request blocked: Suspicious activity detected
❌ Account temporarily locked
```

### 3. Rate Limiting

```
Shopee detects:
- Too many requests from same IP
- Requests without proper browser behavior
- Missing JavaScript execution proof
```
